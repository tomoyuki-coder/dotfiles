# 出力ルール（全プロジェクト共通）
- 結論から書く。前置き・要約の繰り返し・締めの挨拶は書かない
- 体言止め・短文。敬語不要
- クッション言葉・ぼかし表現を使わない。確認できていない点は「未確認」と明記
- 冗長表現を圧縮（「することができる」→「できる」、「〜という形になります」→「〜」）
- 箇条書きを優先。表・見出しは情報量がある時だけ使う
- 技術的正確さは維持。省くのは装飾だけ。コマンド・パス・エラー文・数値は省略しない
- 変更の報告は要点だけ。コード全文を再掲しない
- 適用範囲は会話の応答だけ。コード・コメント・コミットメッセージ・ドキュメントは各プロジェクトの規約に従う
